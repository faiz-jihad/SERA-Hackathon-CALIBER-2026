# SERA — Technical Glossary

---

## 📖 Domain & Technical Terminology

| Term | Definition |
| :--- | :--- |
| **1X Rotational Frequency** | The fundamental running speed frequency of the rotating machine (e.g. $2980\text{ RPM} = 49.67\text{ Hz}$). High 1X amplitude typically indicates mechanical unbalance. |
| **2X Rotational Harmonic** | Twice the running speed frequency ($2 \times 1\text{X}$). Dominant 2X peaks ($> 50\%$ of overall vibration) are the textbook diagnostic indicator of shaft centerline coupling misalignment. |
| **Coupling Radial Offset** | The perpendicular distance between the rotational centerlines of two coupled shafts (e.g. motor and blower), measured in millimeters ($\text{mm}$). Precision limit is $< 0.05\text{ mm}$. |
| **DE (Drive End) Bearing** | The bearing located nearest to the coupling hub. In misaligned trains, the DE bearing absorbs the primary bending moments and friction loads. |
| **DCS (Distributed Control System)** | The central computerized control system (e.g. Emerson DeltaV, Yokogawa Centum) managing automated plant regulatory loops and safety interlock trips. |
| **ISO 10816-3** | International standard defining vibration severity evaluation criteria for industrial machines on rigid foundations ($\text{Zone A: Good}$, $\text{Zone B: Acceptable}$, $\text{Zone C: Alert}$, $\text{Zone D: Trip}$). |
| **LOTO (Lockout / Tagout)** | Critical industrial safety procedure physically isolating electrical switchgear and chemical valves before maintenance disassembles machine components. |
| **NDE (Non-Drive End) Bearing** | The outboard bearing located furthest from the coupling, supporting the opposite end of the rotor shaft. |
| **PTW (Permit to Work)** | Formal legal safety document authorizing specific turnaround work after atmospheric gas testing and electrical isolation are verified. |
| **RCA (Root Cause Analysis)** | Systematic engineering methodology (such as the 5-Why Fault Tree) to isolate the fundamental physical failure origin rather than merely treating superficial symptoms. |
| **Rule Provenance** | The rigorous traceability requirement that every threshold alert must explicitly cite its governing standard, clause, threshold value, and engineering rationale. |
| **SAP PM01** | Standard enterprise SAP Plant Maintenance Work Order order type for corrective breakdown turnarounds. |
| **Soft Foot** | Uneven contact between a machine's mounting feet and its baseplate foundation, creating internal frame distortion and shaft misalignment when bolts are torqued. |
| **TF-IDF** | Term Frequency-Inverse Document Frequency algorithm used by SERA to vectorize historical incident texts and match past failure cases using cosine vector similarity. |
| **Vibration Velocity RMS** | Root Mean Square velocity of machine casing vibration measured in $\text{mm/s}$, representing total vibrational destructive energy. |
